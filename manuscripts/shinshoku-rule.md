# 職場の暗黙のルールは、最初の2週間「観察して記録する」でつかむ

## いま、こんな場面にいませんか

報告を文面で送ったら、「こういうのは口頭で言ってね」と言われた。
会議で最初に意見を言ったら、少し空気が固まった気がした。

前の職場では当たり前だったことが、ここでは違うらしい。けれど、誰も事前に教えてくれない。聞こうにも、何を聞けばいいのかさえ分からない。

## このnoteが向いていない人

- 就業規則や社内規程など、文書で決まっているルールを知りたい人
- ハラスメントなど、問題のある慣習に悩んでいる人。その場合は、社内の相談窓口に相談してください
- 業務の手順そのものを変えたい人(引き継ぎ・受ける側シリーズで扱います)

このnoteが扱うのは、**新しい職場の暗黙のルールをつかむ工程だけ**です。

――――――― ここから有料 ―――――――

## 結論

暗黙のルールは、聞いても教えてもらえないことが多いです。職場の人たち自身が、ルールだと意識していないからです。
最初の2週間は、**報告・相談・会議・退勤の4つの場面だけを観察して、記録してください**。

場面を絞るのは、この4つが、新しく来た人も毎日必ず通る場面だからです。毎日通る場面なら、2週間で十分な回数を観察できます。すべてを観察しようとすると、結局何も記録できません。

## 手順

1. **観察する場面を「報告・相談・会議・退勤」の4つに決める。**
2. **周りの人がその場面でどうしているかを、1日1行記録する。**
3. **2週間たったら、記録のうち前の職場と違う点に印を付ける。**
4. **印を付けた点だけ、信頼できる同僚1人に「この理解で合っていますか」と確かめる。**

手順2の記録は、「報告:課長には口頭、他部署には文面」「退勤:定時後に一言かけてから帰る人が多い」のように、事実だけを書きます。良い悪いの評価は書きません。

手順4で確かめるのは、観察だけでは偶然と習慣の区別がつかないからです。確かめる相手は1人で十分です。
大勢に聞いて回ると、「細かいことを気にする人」という印象を与えかねません。1人に、まとめて確かめる方が自然です。

## つまずきやすい箇所と、その場での対処

**人によってやり方がばらばら**
→ 上司に対してどうしているかを優先して記録します。上司とのやり取りの習慣が、いちばん影響が大きいからです。

**前の職場のやり方の方が合理的に見える**
→ 当面は、今の職場のやり方に合わせます。変えるかどうかは、仕事が1周回ってから判断しても遅くありません。

**ルールがどうしても合わない、つらい**
→ 好みの違いなのか、問題のある慣習なのかを分けて考えます。後者なら、相談窓口や上司に相談してください。

**観察する余裕がない**
→ 1日1行で十分です。記録は帰る前の1分で書けます。
4つの場面のうち、その日に目についたものだけを書けば足ります。空欄の日があっても問題ありません。

## そのまま使えるテンプレート

**観察の記録表**

| 日付 | 場面 | 周りの人のやり方 | 前の職場と違う |
|---|---|---|---|
| 5/8 | 報告 | 課長には口頭で、要点だけ先に言う | ★ |
| 5/9 | 会議 | 若手は先輩の後に発言している | ★ |
| 5/10 | 退勤 | 定時後に一言かけてから帰る | |

**同僚への確かめ方**

> 少し教えてください。課長への報告は、まず口頭で要点を伝えるのがこの部署の流れ、という理解で合っていますか。

## 次に困ること

職場の流れがつかめてくると、まとまった仕事を初めて任されます。期待に応えようとして、完璧に仕上げるまで一人で抱え込みたくなる。
