# 引き継ぎの説明は「聞いてもらう」より「言い直してもらう」――1回の打ち合わせで後任に残る話し方

## いま、こんな場面にいませんか

引き継ぎリストはできた。後任との打ち合わせは1時間。
資料を画面に映して、上から順に説明していく。後任はうなずきながらメモを取り、最後に「大丈夫です」と言う。

それなのに翌週、後任から質問が届く。「月末の取引先への連絡って、何を伝えればいいんでしたっけ」。
説明したはずの内容が、ほとんど残っていない。異動の日まで、もう打ち合わせを何度も入れる余裕はない。

## このnoteが向いていない人

- 引き継ぎリスト(暗黙業務も含めた作業の一覧)が、まだできていない人。先にリストを作ってください
- 引き継ぎ資料の書き方・書式を知りたい人
- 後任に実際の作業をやってもらう「同行」の進め方を知りたい人。これは次回扱います

このnoteが扱うのは、**後任と向き合って口頭で説明する工程だけ**です。

――――――― ここから有料 ―――――――

## 結論

説明が残らないのは、後任が聞き流しているからではありません。**聞いただけでは、理解したかどうかを本人も確かめられない**からです。
1件説明するごとに、後任に**自分の言葉で言い直してもらってください**。言い直せたことだけが、引き継げたことです。

## 手順

1. **打ち合わせの前に、リストを「次に期限が来る順」に並べ替える。**
2. **1回の打ち合わせで扱うのは、上から5件までと決める。**
3. **1件ごとに「目的 → 時期 → やらないと困る人」の順で話す。**
4. **話し終えたら、後任に「最初に何をするか」を言い直してもらう。**
5. **言い直せなかった点だけを、その場でリストに書き足す。**

期限順に並べるのは、異動直後に後任が最初にぶつかる作業から渡すためです。重要度順に並べると、すぐ来る細かい作業が後回しになります。

## つまずきやすい箇所と、その場での対処

**「わかりました」で終わってしまう**
「わかりましたか」と聞くと、ほぼ全員が「はい」と答えます。
→ 質問を「〇月になったら、最初に何をしますか」に変えてください。答えが具体的に出なければ、まだ渡せていません。

**時間内に5件が終わらない**
→ 期限が遠い件は次回に回して構いません。1回で全部終えるより、期限が近い件を確実に渡すほうが事故を防げます。

**後任が年上・経験者で、言い直しを頼みにくい**
→ 「試す」のではなく「自分の説明が足りているか確かめたい」と、主語を自分にして頼みます(文例あり)。

**説明中に、自分でも曖昧な点が出てくる**
→ その場で推測で答えず、「確認して明日までに返します」と期限を付けて保留します。

## そのまま使える文例とテンプレート

**打ち合わせ冒頭の一言**

> 今日は、異動後すぐに時期が来る5件だけを説明します。
> 1件ごとに、私の説明で足りたかを確かめたいので、要点を言い直してもらえると助かります。

**年上・経験者の後任への頼み方**

> 私の説明が分かりにくいところを見つけたいので、最初にやることだけ言ってもらえますか。

**1件あたりの説明メモの型**

| 項目 | 書く内容 |
|---|---|
| 目的 | 何のためにやる作業か(1行) |
| 時期 | いつ、どのくらいの頻度か |
| 困る人 | やらないと誰が困るか |
| 最初の一動作 | 後任が最初にすること(後任の言い直しで確認) |

**打ち合わせ後に送るメール**

> 本日はありがとうございました。説明した5件と、追記した点をリストに反映しました。
> 残りの件は〇日の打ち合わせで説明します。

## 次に困ること

言い直しができても、実際にやってみると手が止まる場面は残ります。作業の細かな順番、相手先への最初の連絡などです。
次回は、後任に1回だけ実際の作業をやってもらい、自分は横で見る「同行」の進め方を扱います。
